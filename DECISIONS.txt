SmartCAT Translate 설계 결정 기록
=================================

[D-001] ChatGPT 계정 연결
상태: 승인
결정: MCP나 비공식 ChatGPT 세션 자동화가 아니라 공식 Codex App Server를 사용한다.
이유: 공식 브라우저 인증, 구독 기반 Codex 사용, 토큰 갱신과 계정 상태 처리를 활용할 수 있다.

[D-002] 데스크톱 기술 기반
상태: 승인
결정: Tauri 2 + React + TypeScript + Rust를 사용한다.
이유: Windows와 macOS를 하나의 저장소에서 지원하고 Electron보다 가벼운 앱을 만들기 위함이다.

[D-003] 플랫폼 빌드
상태: 승인
결정: GitHub Actions의 Windows 및 macOS 실행 환경에서 플랫폼별 설치 파일을 만든다.
주의: macOS 공개 배포에는 Apple 코드 서명과 공증이 필요하다.

[D-004] Codex 실행 환경
상태: 승인
결정: 기존 공식 Codex 설치를 우선 탐색하고, 없으면 앱 전용 폴더에 검증된 공식 Codex를 설치한다.
이유: 비기술 사용자도 별도 명령 입력 없이 로그인하고 사용할 수 있게 한다.

[D-005] 전역 단축키
상태: 승인
결정: 일반 조합과 Ctrl+C, C 같은 연속 입력을 지원한다. 충돌 시 등록 차단, 원인 안내, 대체 조합 추천을 기본으로 하고 경고 후 강제 등록을 허용한다.
제약: 운영체제가 점유 프로그램을 공개하지 않는 경우에는 실행 중인 앱과 알려진 단축키 자료를 이용해 충돌 가능성을 표시한다.

[D-006] 번역 대상
상태: 승인
결정: 텍스트, 이미지, 화면 캡처, DOCX, PPTX, XLSX, PDF를 지원한다.

[D-007] 문서 보존
상태: 승인
결정: 원본과 같은 형식의 새 번역 파일을 만들며 원본은 절대 덮어쓰지 않는다. 저장 후 문서 구조를 다시 검사한다.

[D-008] 화면 구성
상태: 승인
결정: 전체 번역 창, 작은 빠른 번역 팝업, 화면 캡처 결과 창을 제공한다.

[D-009] 번역 설정
상태: 승인
결정: 빠른/균형/정밀 품질, 언어 자동 감지, 언어쌍 즐겨찾기, 단축키별 언어쌍, 문체와 분야, 용어집을 제공한다.

[D-010] 개인정보와 기록
상태: 승인
결정: 번역 기록은 기본 30일간 로컬 암호화 저장하고 시크릿 모드를 제공한다. 토큰, 원문, 번역문은 개발 로그에 기록하지 않는다.

[D-011] 앱 업데이트
상태: 승인
결정: GitHub Releases에서 새 버전을 확인하고 변경 내용을 먼저 표시한 뒤 사용자의 동의를 받아 설치한다.
이유: 예기치 않은 자동 변경을 방지하면서도 비기술 사용자가 쉽게 업데이트할 수 있게 한다.

[D-012] 오류 복구
상태: 승인
결정: 추출, 번역, 재배치, 검증, 저장 단계별 상태를 보존하고 네트워크 중단, 로그인 만료, 사용량 제한, 앱 비정상 종료에서 복구 가능한 작업을 재개한다.

[D-013] 품질 검증
상태: 승인
결정: 단위, 통합, 실제 앱 동작 테스트와 원본 불변성, 문서 구조, 서식, OCR 좌표, 개인정보 비기록 검사를 통과해야 배포한다.

[D-014] 배포
상태: 승인
결정: GitHub Actions에서 Windows와 macOS 설치 파일을 만들고 사전 공개판 검증 후 안정판을 배포한다. 공개판은 플랫폼별 서명과 공증 요건을 적용한다.
