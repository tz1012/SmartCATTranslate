SmartCAT Translate 프로젝트 기록
================================

[2026-08-28] 프로젝트 설계 시작

목표
- Windows와 macOS에서 동작하는 로컬 번역 데스크톱 앱을 만든다.
- DeepL과 유사한 전체 창과 작은 빠른 번역 창을 제공한다.
- 사용자의 ChatGPT 계정을 공식 Codex App Server 인증으로 연결한다.
- 텍스트, 이미지, 화면 캡처, DOCX, PPTX, XLSX, PDF를 번역한다.
- 문서 번역 결과는 원본 서식과 배치를 최대한 유지한 새 파일로 저장한다.
- 계획, 명세, 결정, 변경, 테스트 결과를 프로젝트 내부에 계속 기록한다.

현재까지 승인된 설계
1. 문서 형식은 DOCX, PPTX, XLSX, PDF를 모두 지원한다.
2. 원본 파일은 덮어쓰지 않고 번역 결과를 새 파일로 저장한다.
3. 이미지와 화면 캡처는 번역문을 원래 위치에 배치한 이미지와 원문/번역문 비교 창을 모두 제공한다.
4. 원문 복사, 번역문 복사, 번역 이미지 저장을 모두 제공한다.
5. 단축키 충돌 시 기본적으로 등록을 막고 충돌 가능 프로그램과 기능을 표시한다.
6. 사용 가능한 대체 단축키를 자동 추천하며, 명시적 선택 시 경고 후 강제 등록할 수 있다.
7. DeepL형 전체 창, 작은 번역 팝업, 화면 캡처 결과 창의 UI 방향을 승인했다.
8. 기술 기반은 Tauri 2 + React + TypeScript + Rust로 확정했다.
9. GitHub Actions로 Windows와 macOS 빌드를 생성한다.
10. 기존 Codex 설치와 로그인 상태를 우선 사용하고, 없으면 앱 전용 공식 Codex를 설치한다.
11. 인증과 번역은 공식 Codex App Server를 사용한다.
12. 문서 본문, 표, 텍스트 상자, 머리글/바닥글, PPT 발표자 노트, Word 각주/미주를 번역한다.
13. 댓글, 메모, 숨김 내용, 시트 이름 등은 옵션으로 제공한다.
14. 수식, URL, 파일 경로, 코드, 변수명, 보호 용어는 번역하지 않는다.
15. 번역 결과 저장 후 구조 손상과 요소 개수를 자동 검사한다.
16. 빠른/균형/정밀 번역, 언어쌍 즐겨찾기, 단축키별 언어쌍, 용어집을 제공한다.
17. 기본 번역 설정은 자동 감지 → 한국어, 균형 번역, 자연스러운 문체다.
18. 번역 기록은 기본 30일간 로컬 암호화 저장하며 시크릿 번역을 제공한다.
19. 인증 정보와 번역 원문은 개발 기록 및 오류 기록에 남기지 않는다.
20. GitHub Releases에서 새 버전을 확인하고 변경 내용을 보여준 뒤 사용자 동의를 받아 설치한다.
21. 오류 발생 시 단계별 상태를 보존하고 재시도, 재로그인, 중단 후 복구를 지원한다.
22. 원본 불변성, 문서 구조, 서식 보존, 개인정보 비기록 여부를 자동 검증한다.
23. Windows와 macOS 설치 파일을 GitHub Actions에서 만들고 사전 공개판을 거쳐 안정판을 배포한다.

[2026-08-28 14:08 Asia/Seoul] Codex App Server JSONL 전송 계층

구현
- 검증된 `ResolvedRuntime`이 소유한 초기화 완료 라이브 세션에서 같은 입출력 채널을 인계받아, 실행 경로를 다시 탐색하거나 프로세스를 재실행하지 않는 JSONL 전송 계층을 추가함.
- 단일 writer 작업이 요청 하나를 JSON 한 줄로 기록하고, reader 작업이 응답 ID별 대기 요청과 서버 알림을 분리해 전달하도록 구현함.
- 동시 요청 ID를 원자적으로 할당하고, 응답 순서가 바뀌어도 올바른 요청으로 전달하며, 취소된 요청의 대기 항목을 자동 제거함.
- 프로세스 종료와 명시적 종료 시 모든 대기 요청을 안전한 종료 오류로 해제하고 `runtime/exited` 알림을 정확히 한 번만 발행함.
- 잘못된 JSON, 알 수 없는 메시지와 응답 ID는 다음 정상 응답을 방해하지 않으며, 알려진 요청의 손상된 응답은 안전한 프로토콜 오류로 종료함.
- 서버 오류의 메시지·데이터, 원문·번역문, 토큰과 전체 경로를 오류 문자열이나 내부 로그에 포함하지 않고 숫자 오류 코드만 노출함. 알림의 `Debug` 출력에서도 매개변수를 숨김.
- 입력 JSONL 한 줄에 8 MiB 상한을 두어 줄바꿈 없는 비정상 입력으로 인한 무제한 메모리 증가를 차단함.
