BYOK Translator 자동 기록 정책
=================================

목적
- 프로젝트의 계획, 승인된 결정, 개발 명세, 소스 변경, 테스트 결과를 추적 가능하게 보존한다.

기록 파일
- PROJECT_LOG.txt: 날짜별 진행 상황, 계획, 완료 항목, 검증 결과
- DECISIONS.txt: 설계 결정, 선택 이유, 제약과 변경 이력
- CHANGELOG.md: 사용자에게 보이는 기능 및 동작 변경
- docs/specs/: 승인된 설계 명세와 구현 계획

기록 시점
1. 사용자가 설계 항목을 승인하거나 변경할 때
2. 구현 범위 또는 우선순위가 바뀔 때
3. 소스 코드나 설정 파일이 수정될 때
4. 테스트, 빌드, 패키징, 보안 검사가 실행될 때
5. 알려진 제한이나 실패가 발견될 때

자동화 원칙
- 설계 단계에서는 작업 담당자가 승인 직후 기록 파일을 함께 갱신한다.
- 구현 단계에서는 `pnpm records:add -- --summary "chore: change-slug" --tests "pnpm records:test && 8/8 passed" --files-from-git`으로 변경 파일을 자동 수집해 PROJECT_LOG.txt에 기록한다.
- 요약은 `chore: change-slug`처럼 분류된 변경 식별자만, 검증은 명령과 결과 메타데이터만 기록한다. 토큰, 사용자 절대 경로, 줄바꿈, 제어 문자를 포함한 값과 번역 원문·번역문 같은 자유 서술은 기록하지 않는다.
- 커밋 전에는 `pnpm records:check`으로 staged 제품 변경에 PROJECT_LOG.txt, DECISIONS.txt 또는 CHANGELOG.md 기록이 함께 있는지 검사한다.
- CI는 pull request 또는 push의 base/head 커밋 범위를 같은 규칙으로 검사하고, 초기 push는 빈 트리부터 검사한다. 기록 스크립트 테스트와 함께 누락된 변경 기록을 실패 처리한다.
- 기록 누락이 발견되면 배포 검사를 실패 처리한다.

기록 금지 정보
- ChatGPT/Codex 인증 토큰과 계정 비밀정보
- 번역 원문과 번역문 본문
- OCR로 추출한 개인정보
- 사용자의 전체 로컬 파일 경로
- 임시 문서 및 이미지 내용

앱 기록·복구 정책
- 번역 기록은 기본 사용, 30일 보관이며 SQLite에는 종류·시간·언어 같은 검색용 비민감 메타데이터만 평문으로 둔다. 원문, 번역문, 표시 파일명은 운영체제 자격 증명 저장소의 32바이트 키로 각각 인증 암호화한다.
- Windows Credential Manager 또는 macOS Keychain을 사용할 수 없으면 기록·복구 저장을 실패 폐쇄한다. 평문 키 파일이나 평문 payload로 대체하지 않는다. ChatGPT/Codex 토큰은 Codex만 관리한다.
- 시크릿 번역은 텍스트, 빠른 팝업, 화면·이미지, 문서 모두에서 기록 row를 만들지 않는다. 시크릿 문서 체크포인트는 프로세스 메모리에만 존재하며 앱 재시작 뒤 복구하지 않는다.
- 일반 문서 복구 record는 7일 뒤 삭제하며 source fingerprint와 canonical 전체 옵션 snapshot/hash가 모두 일치할 때만 재개한다. 프로필·모델·품질·용어집·형식 옵션이 바뀌면 이전 결과와 섞지 않고 새 작업만 허용한다.
- 문서·capture 임시 데이터는 하나의 canonical app temp root 아래 앱 생성 UUID 직계 자식에만 만들고 symlink와 Windows reparse point는 따라가지 않는다. 완료·취소와 시작 시 7일 만료 purge에서 해당 작업 디렉터리를 제거한다.
- 진단은 event, outcome, durationMs, jobKind, stage, errorCode, itemCount, byteCount, platform, appVersion 필드만 허용한다. 번역 내용, 전체 경로, 이메일, 인증 정보와 임의 key/value map은 금지한다.
- `pnpm privacy:check`는 기록 문서와 tracked sanitized captured-log 집합에서 토큰 형태, 이메일, 사용자 홈 절대 경로와 canary 원문을 검사한다. 입력 누락, 빈 집합, symlink와 5MiB 초과 파일은 검사 실패다.
