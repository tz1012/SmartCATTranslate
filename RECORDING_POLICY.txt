SmartCAT Translate 자동 기록 정책
=================================

목적
- 프로젝트의 계획, 승인된 결정, 개발 명세, 소스 변경, 테스트 결과를 추적 가능하게 보존한다.

기록 파일
- PROJECT_LOG.txt: 날짜별 진행 상황, 계획, 완료 항목, 검증 결과
- DECISIONS.txt: 설계 결정, 선택 이유, 제약과 변경 이력
- CHANGELOG.md: 사용자에게 보이는 기능 및 동작 변경
- docs/specs/: 승인된 설계 명세와 구현 계획

기록 시점
1. 사용자가 설계 항목을 승인하거나 변경할 때
2. 구현 범위 또는 우선순위가 바뀔 때
3. 소스 코드나 설정 파일이 수정될 때
4. 테스트, 빌드, 패키징, 보안 검사가 실행될 때
5. 알려진 제한이나 실패가 발견될 때

자동화 원칙
- 설계 단계에서는 작업 담당자가 승인 직후 기록 파일을 함께 갱신한다.
- 구현 단계에서는 변경 기록 스크립트와 커밋 전 검사를 추가한다.
- CI 빌드는 빌드 대상, 버전, 테스트 결과, 산출물 정보를 기록한다.
- 기록 누락이 발견되면 배포 검사를 실패 처리한다.

기록 금지 정보
- ChatGPT/Codex 인증 토큰과 계정 비밀정보
- 번역 원문과 번역문 본문
- OCR로 추출한 개인정보
- 사용자의 전체 로컬 파일 경로
- 임시 문서 및 이미지 내용
